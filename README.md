# Tech Helper

Tech Helper is a work-in-progress prototype for plain-language technology guidance designed with older adults in mind.

The project was initially built in Base44. This repository contains a static portfolio demonstration of the concept, including:

- senior-friendly typography and navigation;
- everyday device-help categories;
- healthcare guide topics such as patient portals and telemedicine;
- interactive emergency troubleshooting examples;
- a larger-text control; and
- searchable guide categories.

This portfolio version does not represent a finished product, medical advice, or an emergency service.

## Run locally

Open `index.html` in a browser or serve the directory with any static web server.

## GitHub Pages

The site has no build step. Enable GitHub Pages for the repository's default branch and root directory.
