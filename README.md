# Tech Helper

Tech Helper is a work-in-progress technology-support prototype originally built in Base44. This repository restores the exported React source into its intended project structure.

The project is designed around plain-language technology support for people who may be less comfortable with digital tools. Examples include device accessibility, troubleshooting, patient portals, online appointment systems, virtual-visit setup, DocuSign, and everyday communication tools.

**Important:** Tech Helper does not provide medical advice or clinical guidance. Its care-related content is about navigating the technology used by care providers and related services.
